Python package clustaudio is for unsupervised clustering of audio files.

Name : clustaudio.py Author : E.Taskesen (adapted for audio by AI assistant) Contact : erdogant@gmail.com github : https://github.com/erdogant/clustaudio Licence : See licences

DescriptionAudio clustering library for organizing, analyzing, and finding similar audio files

using various feature extraction methods and clustering algorithms.

class clustaudio.clustaudio.clustaudio(method='mfcc', embedding='tsne', sr=22050, duration=None, mono=True, normalize=True, trim_silence=False, dirpath=None, use_audio_cache=True, use_spectrogram_cache=True, tempdir=None, ext=['wav', 'mp3', 'flac', 'ogg', 'm4a', 'aac'], params_pca={'n_components': 0.95}, params_mfcc={'hop_length': 512, 'n_fft': 2048, 'n_mels': 128, 'n_mfcc': 13}, params_spectral={}, params_chroma={'n_chroma': 12}, params_fingerprint={'algorithm': 'chromaprint'}, params_metadata={'cluster_by': ['artist', 'album', 'genre'], 'similarity_threshold': 0.8}, ncores=4, verbose='info')

Clustering of audio files.

Clustering audio files through pre-processing, feature extraction, embedding and cluster evaluation. This library enables:

  • Organizing large audio collections by similarity

  • Finding duplicate or similar audio files

  • Genre/mood-based clustering

  • Voice segment extraction

  • Playlist generation from clusters

The following steps are taken:

  • Step 1. Pre-processing:

    Audio files are imported with specific extensions ([‘wav’, ‘mp3’, ‘flac’, ‘ogg’, ‘m4a’]). Each audio file is loaded with a target sample rate and can be converted to mono. Audio can be normalized and trimmed for silence.

  • Step 2. Feature extraction:

    Features are extracted using various methods: - ‘mfcc’: Mel-Frequency Cepstral Coefficients (default) - ‘spectral’: Spectral features (centroid, rolloff, contrast, bandwidth) - ‘chroma’: Chromagram features for pitch/harmony analysis - ‘mfcc-spectral’: Combined MFCC and spectral features - ‘tempogram’: Tempo and rhythm features - ‘embeddings’: Deep learning audio embeddings (VGGish, YAMNet, OpenL3) - ‘fingerprint’: Audio fingerprinting for duplicate detection - ‘metadata’: Use audio metadata (ID3 tags) for clustering

  • Step 3. Embedding:

    The feature space is transformed non-linearly using t-SNE or UMAP. The embedding coordinates are used for visualization.

  • Step 4. Cluster evaluation:

    The feature space is used for cluster evaluation to determine the optimal number of clusters using silhouette, dbindex, or derivative methods.

  • Step 5. Results and visualization:

    Results are stored and can be visualized using waveforms, spectrograms, scatter plots, and cluster-based audio playback.

Parameters:

  • method (str, (default: 'mfcc')) –

    Method to extract features from audio files:

    • ’mfcc’ : Mel-Frequency Cepstral Coefficients

    • ’spectral’ : Spectral features (centroid, rolloff, contrast, bandwidth)

    • ’chroma’ : Chromagram features

    • ’mfcc-spectral’ : Combined MFCC and spectral features

    • ’tempogram’ : Tempo and rhythm features

    • ’mel-spectrogram’ : Mel-scaled spectrogram

    • ’embeddings’ : Deep learning embeddings (requires additional setup)

    • ’fingerprint’: Audio fingerprinting for duplicates

    • ’metadata’: Cluster by audio metadata (artist, album, genre, etc.)

    • None : Use raw audio features

  • embedding (str, (default: 'tsne')) –

    Perform embedding on extracted features for visualization:

    • ’tsne’ : t-SNE embedding

    • ’umap’ : UMAP embedding

    • None : Use first two features for plotting

  • sr (int, (default: 22050)) – Target sample rate for audio loading (Hz). Common values: 22050, 44100, 48000

  • duration (float or None, (default: None)) – Maximum duration to load from each audio file (seconds). None = load entire file Setting a value (e.g., 30) loads only first N seconds.

  • mono (bool, (default: True)) – Convert audio to mono (single channel). False: Keep stereo/multi-channel audio

  • normalize (bool, (default: True)) – Normalize audio amplitude to [-1, 1] range.

  • trim_silence (bool, (default: False)) – trim_silence audio silence

  • dirpath (str, (default: 'clustaudio')) – Directory to write temporary files and extracted segments.

  • ext (list, (default: ['wav', 'mp3', 'flac', 'ogg', 'm4a', 'aac'])) – Audio file extensions to process.

  • params_pca (dict, default: {'n_components':0.95, 'detect_outliers':None}) – Parameters for PCA dimensionality reduction (used with some methods).

  • params_mfcc (dict, default: {'n_mfcc':13, 'n_fft':2048, 'hop_length':512}) –

    Parameters for MFCC feature extraction:

    • ’n_mfcc’: Number of MFCC coefficients (typically 13-40)

    • ’n_fft’: FFT window size

    • ’hop_length’: Number of samples between successive frames

    • ’n_mels’: Number of mel bands (default: 128)

    • ’fmin’: Minimum frequency (Hz, default: 0)

    • ’fmax’: Maximum frequency (Hz, default: None = sr/2)

  • params_spectral (dict, default: {}) – Parameters for spectral feature extraction (uses librosa defaults).

  • params_chroma (dict, default: {'n_chroma':12}) –

    Parameters for chroma feature extraction:

    • ’n_chroma’: Number of chroma bins (default: 12)

  • params_fingerprint (dict, default: {'algorithm':'chromaprint'}) –

    Parameters for audio fingerprinting:

    • ’algorithm’: ‘chromaprint’ or other fingerprinting method

  • params_metadata (dict, default: {'cluster_by':['artist', 'album', 'genre']}) –

    Parameters for metadata-based clustering:

    • ’cluster_by’: List of metadata fields to use

    • ’similarity_threshold’: Threshold for string matching (0-1)

  • use_audio_cache (bool (Default: True)) – Cache extracted features to disk for faster reprocessing.

  • use_spectrogram_cache (bool (Default: True)) – Cache computed spectrograms to speed up visualization.

  • ncores (int, (default: 4)) – Number of CPU cores for parallel processing.

  • verbose (int or str, (default: 'info')) – Logging level. Options: ‘debug’, ‘info’, ‘warning’, ‘error’ Or numeric: 10 (debug), 20 (info), 30 (warning), 40 (error)

Returns:

resultsdict
Dictionary with clustering results:

  • feat : Extracted features array

  • xycoord : 2D embedding coordinates

  • pathnames : List of file paths

  • filenames : List of file names

  • labels : Cluster labels

  • sample_rates : Sample rates of loaded files

  • durations : Duration of each file

Return type:

Object containing

audioread(filepath, sr=None, duration=None, offset=0.0, mono=None, normalize=None, return_success=False)

Read and preprocess audio file.

This function loads audio files and applies preprocessing steps: 1. Load audio with target sample rate 2. Convert to mono (optional) 3. Normalize amplitude (optional)

Parameters:

  • filepath (str) – Path to audio file

  • sr (int or None) – Target sample rate (Hz). If None, uses self.params[‘sr’]

  • duration (float or None) – Duration to load (seconds). If None, uses self.params[‘duration’]

  • offset (float) – Start reading after offset (seconds)

  • mono (bool or None) – Convert to mono. If None, uses self.params[‘mono’]

  • normalize (bool or None) – Normalize amplitude. If None, uses self.params[‘normalize’]

  • return_success (bool) – If True, return (audio, success) tuple

Returns:

  • audio (np.ndarray) – Audio waveform, shape (n_samples,) for mono or (n_channels, n_samples) for stereo

  • success (bool (only if return_success=True)) – Whether the audio was successfully loaded

Examples

>>> from clustaudio import clustaudio
>>>
>>> cl = clustaudio()
>>> audio = cl.audioread('audio.wav', sr=22050, mono=True)
>>> print(audio.shape)

Cluster audio files based on their acoustic similarity.

This is the main workflow method that: 1. Imports audio files 2. Extracts features 3. Computes embedding for visualization 4. Evaluates and determines optimal clusters 5. Returns clustering results

    Input audio files:

  • evaluate (str) – Cluster evaluation method: ‘silhouette’, ‘dbindex’, ‘derivative’

  • linkage (str) – Linkage method for hierarchical: ‘ward’, ‘single’, ‘complete’, ‘average’

  • min_clust (int) – Minimum number of clusters to evaluate

  • max_clust (int) – Maximum number of clusters to evaluate

  • cluster_space (str) – Feature space for clustering: ‘high’ (original) or ‘low’ (embedded)

  • black_list (list) – Directories to exclude from scanning

  • recursive (bool) – Scan subdirectories recursively

Returns:

Results dictionary containing:

  • feat: Extracted features

  • xycoord: 2D embedding coordinates

  • pathnames: File paths

  • filenames: File names

  • labels: Cluster labels

  • sample_rates: Sample rates

  • durations: Audio durations

Return type:

dict

Examples

>>> from clustaudio import clustaudio
>>>
>>> # Initialize
>>> cl = clustaudio(method='mfcc', sr=22050)
>>>
>>> # Cluster audio files
>>> results = cl.fit_transform('path/to/music/')
>>>
>>> # Visualize

preprocessing(pathnames, sr=None, duration=None, mono=None, normalize=None, trim_silence=False, flatten=False)

Preprocess audio files and return consistent output.

This function handles multiple input types and applies preprocessing: 1. Load audio files 2. Convert to target sample rate 3. Convert to mono (optional) 4. Trim silence (optional) 5. Normalize amplitude (optional)

Parameters:

  • pathnames (str, list, or np.ndarray) –

    Input audio files:

    • str: Path to directory or single file

    • list: List of file paths

    • np.ndarray: Pre-loaded audio array

separate_foreground_background(pathnames, output_dir=None, method='spectral_masking', denoise=True, denoise_method='spectral', save_both=True)

Separate foreground (signal) from background (noise) in audio files.

This is particularly useful for noisy communications like ATC, radio transmissions, or any audio with significant background noise. Similar to VAD but extracts both signal and noise components.

Parameters:

  • pathnames (str or list) – Path(s) to audio file(s)

  • output_dir (str, optional) – Output directory for separated files

  • method (str) –

    Separation method:

    • ’spectral_masking’: Spectral masking based on SNR (default)

    • ’harmonic_percussive’: HPSS-based separation

    • ’nmf’: Non-negative matrix factorization

    • ’wiener’: Wiener filter approach

  • denoise (bool) – Apply denoising before separation

  • denoise_method (str) – Denoising method: ‘spectral’, ‘wiener’, ‘bandpass’, ‘noisereduce’

  • save_both (bool) – Save both foreground and background files

Returns:

Dictionary containing:

results : List of separation results per file pathnames_foreground : Paths to foreground audio files pathnames_background : Paths to background audio files snr_db : Signal-to-noise ratios

Return type:

dict

Examples

>>> cl = clustaudio(method='mfcc')
>>>
>>> # Separate foreground/background
>>> results = cl.separate_foreground_background(
...     'ATC_recording.wav',
...     method='spectral_masking',
...     denoise=True
... )
>>>
>>> # Cluster foreground (voice)
>>> voice_clusters = cl.fit_transform(results['pathnames_foreground'])
>>>
>>> # Cluster background (noise types)
>>> noise_clusters = cl.fit_transform(results['pathnames_background'])
